🎩 Pointy Hat Modular Method (Summary)

Goal: Design one-shots that reliably finish in a single session, while still feeling meaningful and choice-driven.

Core Steps
	1.	Start Fast
	•	PCs already know each other.
	•	Quest is already accepted.
	•	Give players the setup in a few sentences, then begin.
	2.	Define the Quest
	•	One clear mission (rescue, infiltrate, survive, retrieve, etc.).
	•	Keep it tight: one beginning, middle, and end.
	3.	Fork the Path
	•	Offer 2 choices:
	•	Path of Least Resistance → direct, obvious, quicker.
	•	Path Less Traveled → harder or longer, but grants a Key.
	4.	Use Keys
	•	Keys = items, info, allies, or tools.
	•	They unlock options in later encounters or the showdown.
	•	Make the Key path feel rewarding but optional.
	5.	Modular Encounters
	•	Plan 3–4 encounters (≈1 hour each).
	•	Types: Combat, Roleplay, Exploration, Puzzle.
	•	Mark each encounter as modular so you can skip, shorten, or swap.
	6.	Showdown
	•	Always include a climax (boss fight, roleplay trial, escape).
	•	Choices and Keys matter most here.
	•	The ending shows consequences of earlier decisions.

⸻

Quick Skeleton Prompt
	•	Quest: What is the clear mission?
	•	Forks: What’s the easy path vs. harder Key path?
	•	Keys: What special resource changes the end?
	•	Encounters: 3–4 modular scenes, each 1 hour max.
	•	Showdown: Big climax, altered by choices and keys.

🎲 The Pointy Hat Modular Method for Oneshots (MMO)

Goal: design a one-session adventure that actually fits into one session while still giving players meaningful choices.

1. Skip the Long Intro

Don’t waste an hour in a tavern.

Start in media res — players already know each other (met an hour/day ago).

Quest is already accepted. Brief out-of-character description: “Today’s mission is X.”

2. Keep It Linear (with Choices)

Sandbox = too big for a one-shot.

Use a clear quest framework (rescue, infiltration, survival, test).

Linear or branching is fine, but don’t try to be a full open world.

3. Align the Table

Everyone agrees: the goal is a self-contained one-session adventure.

Players shouldn’t derail on purpose.

If the premise is “save the princess,” make PCs who would actually care about saving the princess.

4. Embrace Modularity

Design encounters so they can be removed, shortened, or swapped.

Rule of thumb: 1 encounter ≈ 1 hour.

Plan more than you need, but expect to cut to the showdown if time runs short.

5. Use Keys

At every fork, offer:

Path of Least Resistance → simple, direct, obvious.

Path Less Traveled → harder/longer, but grants a Key.

A Key = something that unlocks more choices later (info, item, ally, etc.).

Almost all groups go for the interesting path — but presenting both makes the choice feel real.

6. Encounter Mix

Choose 3–4 modular encounters:

2 combats

1 roleplay or exploration/puzzle

Optional extras (only if you have time)

7. The Showdown

Always end with a climax (combat boss, tense roleplay, escape sequence, etc.).

The final choices matter most:

Which Keys were collected?

Who did the PCs help or ignore?

Did they treat allies well?

End consequences can be dramatic or wild — it’s a one-shot, so no campaign balance needed.

Quick Example Skeleton

Theme: Fiends
Quest: Rescue a loved one from the Pantomime King (a devil lord playing king in ruined castle).

Path of Least Resistance → straight up the tower.

Path Less Traveled → detour to rescue a thief girl in the dungeon (Key = knowledge on how to break the devil’s enchantments).

Encounters:

Stealth/library scene with enchanted servants (skip if needed).

Fight with devilish castellan.

Optional: dungeon with living lock devil.

Showdown: Ballroom battle with Pantomime King. Keys alter outcome.

👉 The method’s beauty: you can finish in one session because you’re free to skip straight to the showdown at any time without breaking story flow.
