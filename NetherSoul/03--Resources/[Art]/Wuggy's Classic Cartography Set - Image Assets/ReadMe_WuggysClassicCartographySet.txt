ABOUT
# # # # # # # # # # # # # # # # # # #

This asset pack is hand drawn by me, Ari-Matti Toivonen. It was originally assembled together when I wanted to create a fantasy map loosely based on the general area where a lot of my family is from (the general Haukipudas region in Finland). I hope you find what's provided here useful!
