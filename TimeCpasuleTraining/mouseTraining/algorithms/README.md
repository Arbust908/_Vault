# Algorithm Practice

These are concrete TypeScript exercises from the study list in `initial.md`. Implement each starter file in its matching `solutions/` directory or create a test beside it. State time and space complexity before optimizing.

1. Implement a `Set` without built-in collection helpers.
2. Group records by a property.
3. Merge overlapping intervals.
4. Process commands against in-memory state.
5. Implement an LRU cache.
6. Deduplicate events while preserving order.
7. Run promises with maximum concurrency.
8. Build a retry queue.
9. Flatten and normalize nested API data.
10. Find the shortest path in a grid.

The prompts intentionally leave some policy decisions open. Ask clarifying questions, document assumptions, and test empty input and invalid input.
