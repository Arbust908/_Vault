# Senior Frontend Discussion

Answer as if an interviewer asked you to justify a decision in the code you just wrote.

1. How do you choose component boundaries without creating either one giant component or dozens of trivial wrappers?
2. What belongs in a custom hook, and what belongs in a presentational component?
3. When is `useMemo` or `useCallback` justified, and why is adding it by default often counterproductive?
4. How would you test a calculator state transition separately from its rendered buttons?
5. What accessibility checks would you make for a calculator keypad and a searchable result list?
6. How would you profile a slow React screen before optimizing it?
7. What does test-driven development look like in a one-hour live-coding exercise?
8. How would you explain a deliberate simplification that you would replace in production?
