# Product Context: Proxima Connection

## Purpose
This project aims to create a compelling cyberpunk visual novel, "Proxima Connection," using the Narrat Engine. The primary focus is on delivering an engaging narrative experience driven by player choice within the unique setting of Neo Meridian. This vault serves as the central hub for documentation, planning, and knowledge management related to the project, while the final game build will reside externally.

## Problems Solved (by this project within the vault)
1.  **Narrative Complexity Management**: Provides a structured way to organize branching storylines, character arcs, and world lore.
2.  **Development Coordination**: Acts as a central reference point for design decisions, asset requirements, and scripting logic.
3.  **Knowledge Preservation**: Captures the design intent, setting details, and character motivations for consistency.
4.  **Workflow Definition**: Outlines the process for moving from concept and documentation (in the vault) to implementation (in the external Narrat project).

## Intended Workflow
1.  **Design & Documentation (Vault)**:
    *   Develop world-building details for Neo Meridian (`docs/world/`).
    *   Create character profiles and relationship maps (`docs/characters/`).
    *   Outline plot, scenes, and branching choices (`docs/story/`).
    *   List required assets (`assets/`).
    *   Potentially draft or manage script snippets (`scripts/`).
    *   Maintain project context in this Memory Bank (`memory-bank/`).
2.  **Implementation (External Narrat Project)**:
    *   Configure Narrat Engine (`narrat/config.yaml`, etc.).
    *   Implement narrative using Narrat scripts (`narrat/scripts.yaml`).
    *   Integrate final visual and audio assets (`public/`).
    *   Build and test the game.
3.  **Iteration**:
    *   Use vault documentation to guide implementation changes.
    *   Update vault documentation based on implementation discoveries or changes.

## User Experience Goals (for the final Visual Novel)
-   **Immersive Storytelling**: Engage players with a rich narrative and well-developed characters.
-   **Meaningful Choices**: Ensure player decisions have noticeable impacts on the story and relationships.
-   **Atmospheric World**: Convey the cyberpunk aesthetic and mood of Neo Meridian through visuals, audio, and writing.
-   **Intuitive Interface**: Provide a clean and easy-to-use UI suitable for a visual novel.
-   **Consistent Tone**: Maintain a cohesive cyberpunk style throughout the experience.
-   **Clear Narrative Progression**: Help players understand the consequences of their choices and the overall story flow.
