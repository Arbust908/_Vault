# Project Brief: Proxima Connection

## Overview
Proxima Connection is a cyberpunk visual novel set in the unique megacity of Neo Meridian. It explores themes of technology, society, and identity through a branching narrative driven by player choices. This project is developed using the Narrat Engine, with documentation and planning managed within this Obsidian vault.

## Core Requirements
1. Compelling branching narrative structure
2. Engaging character development and relationships
3. Rich cyberpunk world-building (Neo Meridian)
4. Functional visual novel implementation using Narrat Engine (external project directory)
5. Consistent visual and audio asset integration (managed within Narrat project)
6. Clear documentation of narrative design, world-building, and character arcs within this vault.

## Goals
- Create an immersive cyberpunk visual novel experience focused on story and characters.
- Develop the unique setting of Neo Meridian with distinct factions, locations, and themes.
- Implement meaningful player choices with tangible consequences reflected in the narrative.
- Utilize the Narrat Engine effectively for visual novel mechanics in the external project.
- Maintain comprehensive documentation within this vault to guide development.
- Establish a clear workflow for narrative scripting, asset integration, and documentation updates.

## Scope (within this Vault)
- **Narrative Design:** Plot outlines, branching diagrams, scene descriptions (`docs/story/`).
- **Character Development:** Profiles, relationship maps, backstories (`docs/characters/`).
- **World Building:** Neo Meridian setting details, factions, locations, technology (`docs/world/`).
- **Asset Planning:** Lists and descriptions of required assets (references stored in `assets/`).
- **Script Management:** Potential storage or linking of Narrat `.yaml` scripts (`scripts/`).
- **Project Memory Bank:** This folder (`memory-bank/`) containing project-specific context.

## External Scope (Narrat Project Directory - e.g., `../proxima-connection-vn/`)
- Narrat Engine configuration files (`narrat/`).
- Final Narrat script files (`narrat/scripts.yaml`, etc.).
- Game assets (`public/img/`, `public/audio/`).
- Engine source code (`src/`) if customized.
- Built game application.
